# Muhammad Sultan Fahreza — Next.js Portfolio

This project uses the same kind of editable project structure shown in your screenshot: `app/`, `components/`, `public/`, `package.json`, and TypeScript configuration.

## Run in VS Code (Windows)
1. Extract the ZIP.
2. Open the extracted folder in VS Code (**File → Open Folder**).
3. Open Terminal → New Terminal.
4. Run:
   ```bash
   npm install
   npm run dev
   ```
5. Open `http://localhost:3000`.

## Deploy free to Vercel
1. Create a GitHub repository and push this project.
2. In Vercel, select **Add New → Project**.
3. Import the GitHub repository.
4. Vercel detects Next.js automatically.
5. Click **Deploy**. No paid hosting or custom build command is required.

## Main files to edit
- `app/page.tsx` — page entry
- `components/Portfolio.tsx` — portfolio content and sections
- `components/GeoScene.tsx` — interactive 3D geological model
- `app/globals.css` — design, colors, responsive layout
- `app/layout.tsx` — page title and metadata
- `public/CV-Muhammad-Sultan-Fahreza.pdf` — downloadable CV

The 3D scene is interactive: drag to rotate the geological model. The illustration is conceptual artwork, not real well-log data. Please verify all CV details and contact information before publishing.
